# 验证记录与边界

2026-10-12 原型版本已完成的合成测试摘要：

| 检查 | 结果 |
| --- | --- |
| 正常输入 | 9 / 9 通过 |
| 异常输入 | 3 / 3 正确拒绝 |
| 原输入哈希 | 12 / 12 不变 |
| 正常结果的独立内容审计 | 9 / 9 通过 |

正常输入包括标准 DOCX、简单 DOCX、扩展名伪装为 WPS/DOC 的 DOCX、DOC、扩展名为 WPS 的 DOC、RTF、扩展名为 DOC 的 RTF，以及 ODT。异常输入包括截断 DOCX、纯文本伪装的 WPS 和缺少文档结构的 ZIP。

合成内容覆盖中文和拉丁文字、标点、数字、普通与不换行空格、全角空格、制表符、显式换行、字体样式、编号、分页、表格、图片、页眉页脚、动态页码、脚注与批注。审计比较可见文字、表格数量、图片尺寸及解码后的像素数据，并分开核对非正文内容。有效 DOCX 复制路径另行检查字节一致。

转换格式使用自身导入的 ODT 视图作为比较基准；因此审计不能发现导入引擎在读取原格式时已经丢失的所有元素。DOC 正文和相关 story 文本另有独立二进制读取核对；RTF/ODT 不具备同等独立读取覆盖。动态页码、格式控制字符和部分版式换行不会被当作正文文字差异。

合成用例没有包含真实金山私有格式。测试通过不能推出所有 WPS 文档可转换，也不能证明 Word 的分页、布局或所有复杂对象完全相同。源文件及含个人路径的完整本地测试报告不提交到仓库。

2026-10-17 新增 `test_header_regressions.py`，由 `run_tests.py` 一并执行，也可以单独运行：

```sh
python3 tests/test_header_regressions.py --engine /absolute/path/to/LibreOffice.app/Contents/MacOS/soffice
```

该测试生成普通页眉页脚、首页与奇偶页不同、同文变体、分节独立、全部共享、部分共享、后续分节显式清空、重复文字、静态数字与 PAGE/NUMPAGES、无实际注释的分隔符、真实脚注尾注等合成 DOC。独立读取结果 DOCX 的正文、每节有效页眉页脚引用、页尺寸、页码域类型及注释内容，逐项比较。原始输入另行核验哈希不变。

坏输出用例包括删除页眉、修改页脚、删除重复文字、修改静态页码和编号、丢失正文字符、交换奇偶页引用、交换不同节引用，以及在变体文字相同的情况下改变奇偶页开关。它们通过实际发布门禁，要求拒绝且不留下输出。另有手工 PlcfHdd 索引用例，检查 UTF-16 字符位置、分隔槽和页眉文字的边界以及损坏索引；非分隔槽中的控制字符或分隔槽中的自定义文字不能被任意忽略。

LibreOffice 的 DOC 导出器会在生成合成 DOC 时丢弃部分自定义脚注分隔文字，因此不能用这样的空白导出样本宣称自定义分隔文字保留。该边界使用独立二进制读取元数据中的可见分隔文字进行审计，确认候选输出缺失这些文字时仍会被拒绝。测试不代表所有复杂分页或版式都已得到视觉验证。

0.1.2 本机验证结果：原有多格式矩阵 9 个正常输入通过、3 个异常输入正确拒绝；新增 11 个正常 DOC 通过、11 个缺失或篡改候选正确拒绝、4 个二进制索引边界检查通过。所有输入哈希保持不变。

`test_layout_preservation.py` 的 7 项测试核验中文字符网格修复：有效正数、负数和无网格文档整包字节不变；仅修复新导出的 DOCX 中误写为无符号整数的负字距；保留其他 XML 字节、命名空间、正文及 ZIP 成员，并检查修复幂等与越界拒绝。这些测试也由 `run_tests.py` 执行。

一份真实旧 DOC 在修复前被页眉页脚校验误拒绝；修复后正文逐字符一致，原件哈希不变。输出经捆绑引擎渲染并逐页查看，两页正文换行、分页、页眉横线及页码保留，无裁切或重叠；原字体缺失仍使标题采用替代字体，某一编号缩进约有 11 pt 差异。Word 原生渲染验证未完成，不能将此次结果称为所有字体或版式完全相同。

2026-10-19 的 0.1.3 增加 `test_body_regressions.py`，由 `run_tests.py` 一并运行。它覆盖老 DOC 的不可断连字符和可选连字符与 DOCX 元素、Unicode 字面量之间的等价表示：4 项正向完整转换通过，18 项实际缺失或篡改候选被拒绝，8 项正文及其他故事读取检查通过；所有合成原件哈希不变。负向用例包括把不可断连字符改为普通减号、丢失软连字符、文字错序、普通空格/NBSP/全角空格及静态数字变化，并覆盖页眉、页脚、脚注和尾注。

一份真实 WPS 扩展名的 DOC 因两个不可断连字符被旧校验器漏读而误报正文少字。修复后 50 个段落、4402 个可见字符（含两个不可断连字符）核对一致，其他内容核验通过。原文件声明的“国标仿宋、国标楷体”等字体在本机缺失，DOC 与 DOCX 的字体替代策略不同，导致正文外观和换行变化；保留原字体声明，不把修复字符误报描述为解决了全部排版问题。未完成 Word 原生版式验证。
