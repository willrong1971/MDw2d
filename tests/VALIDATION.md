# 验证记录与边界

2026-10-12 原型版本已完成的合成测试摘要：

| 检查 | 结果 |
| --- | --- |
| 正常输入 | 9 / 9 通过 |
| 异常输入 | 3 / 3 正确拒绝 |
| 原输入哈希 | 12 / 12 不变 |
| 正常结果的独立内容审计 | 9 / 9 通过 |

正常输入包括标准 DOCX、简单 DOCX、扩展名伪装为 WPS/DOC 的 DOCX、DOC、扩展名为 WPS 的 DOC、RTF、扩展名为 DOC 的 RTF，以及 ODT。异常输入包括截断 DOCX、纯文本伪装的 WPS 和缺少文档结构的 ZIP。

合成内容覆盖中文和拉丁文字、标点、数字、普通与不换行空格、全角空格、制表符、显式换行、字体样式、编号、分页、表格、图片、页眉页脚、动态页码、脚注与批注。审计比较可见文字、表格数量、图片尺寸及解码后的像素数据，并分开核对非正文内容。有效 DOCX 复制路径另行检查字节一致。

转换格式使用自身导入的 ODT 视图作为比较基准；因此审计不能发现导入引擎在读取原格式时已经丢失的所有元素。DOC 正文和相关 story 文本另有独立二进制读取核对；RTF/ODT 不具备同等独立读取覆盖。动态页码、格式控制字符和部分版式换行不会被当作正文文字差异。

合成用例没有包含真实金山私有格式。测试通过不能推出所有 WPS 文档可转换，也不能证明 Word 的分页、布局或所有复杂对象完全相同。源文件及含个人路径的完整本地测试报告不提交到仓库。
